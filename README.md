# 🍔 Foodie — Food Ordering App

A modern and responsive food ordering web application built with React and JavaScript. Foodie provides a smooth ordering experience with a dynamic food menu, shopping cart management, quantity controls, checkout validation, tip selection, and responsive design.

## ✨ Features

* 🍕 Dynamic food menu with categories, descriptions, ratings, and prices
* 🛒 Add food items to the shopping cart
* ➕ Increase and decrease item quantities
* 🗑️ Remove items from the cart
* 🧹 Clear the entire cart
* 💰 Automatic subtotal, delivery fee, tax, and total calculations
* 📍 Delivery address validation
* 💵 Select a courier tip percentage
* ✅ Order confirmation with success notification
* 📱 Fully responsive across desktop, tablet, and mobile
* 🎨 Modern UI with animations, hover effects, and responsive layouts
* ⚡ Fast and interactive React-based user experience

## 🛠️ Tech Stack

* **React** — Component-based UI development
* **JavaScript (ES6+)** — Application logic and state management
* **HTML5** — Semantic structure
* **CSS3** — Responsive design, animations, gradients, and layouts
* **Vite** — Development environment and build tool
* **Git & GitHub** — Version control and project management

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/siemg22/Food-Ordering-App.git
```

Navigate into the project:

```bash
cd Food-Ordering-App
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
